# Takathamani UI

**Takathamani** is an inclusive agricultural-waste marketplace connecting farmers, buyers, and administrators to turn farm waste into value, promote a circular economy, and bridge agricultural production with industrial demand.

## 🚀 Features

* **Interactive Dashboard:** Real-time metrics, environmental impact tracking ($CO_2$ avoided and waste recovered), and quick actions.
* **Marketplace & Smart Matching:** AI-powered matching connecting buyers with relevant agricultural waste (e.g., maize cobs, rice husks, bagasse).
* **Map & Collection Routes:** Optimized collection routes and farm listing locations.
* **Payments & Transactions:** Secure mobile-money integration and transaction tracking.
* **USSD Integration:** Inclusive access design for basic-phone users.
* **User Profiles & Settings:** Role-based management for farmers, buyers, and administrators.

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Vite
* **Styling:** Tailwind CSS
* **Icons / Assets:** Responsive UI components

## 📦 Getting Started

Follow these simple instructions to set up and run the project locally.

### Prerequisites

Ensure you have **Node.js** (v16 or higher) and **npm** installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone [https://github.com/username/Takathamani-UI.git](https://github.com/username/Takathamani-UI.git)
   cd Takathamani-UI
   ```
   ### Install dependencies:
   ```
   npm install
   ```
   ### Start the local development server:
   ```
   npm run dev
   ```
